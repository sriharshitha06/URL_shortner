# Module 01 Quick Pass

## 5 Explicit Requirements
1. Users can book time slots.
2. Users can pay through the platform.
3. Users can browse providers by category.
4. Users can view provider profiles with ratings.
5. Users receive confirmation emails after booking.

## 2 Ambiguities
1. Is a time slot reserved before payment or only after successful payment?
2. Does booking become confirmed automatically on payment, or does the provider still need to approve it?

## 1 PM Question
When exactly should a booking become confirmed, and what should happen to the slot if payment fails?
